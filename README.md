# Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

This project is a basic recipe website created using **HTML only**. It contains multiple recipe pages that can be accessed through links from the homepage.

The main goal of this project was to practice the fundamentals of HTML, including:

- Creating a basic HTML structure
- Using headings and paragraphs
- Creating links with `<a>`
- Adding images with `<img>`
- Creating ordered and unordered lists
- Organizing content with HTML elements

## Built With

- HTML5

## What I Learned

Through this project, I practiced building a simple multi-page website using only HTML and learned how different HTML elements work together to structure web content.
